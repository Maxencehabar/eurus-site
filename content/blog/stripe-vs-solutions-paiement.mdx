## Qu'est-ce que Stripe ?

Stripe est une infrastructure de paiement fondée en 2010 par les frères Collison. C'est la référence pour les développeurs et les startups tech.

**Chiffres clés 2026 :**
- **80.1% des entreprises IT** l'utilisent (SQ Magazine 2026)
- **Valorisation** : 50+ milliards $ (dernière levée)
- **Volume traité** : centaines de milliards $/an
- Utilisé par **Amazon, Google, Shopify, Slack, Zoom**

**Frais Stripe Europe (2026) :**
- Carte européenne : **1.5% + 0.25€**
- Carte UK : **2.5% + 0.25€**
- Carte internationale : **2.9% + 0.25€**
- Paiements récurrents : +0.5%
- Stripe Connect (marketplace) : +0.5% ou +2€/paiement

**Ce que Stripe apporte :**
- API exemplaire (la référence du marché)
- Stripe Elements (UI préconstruite)
- Stripe Checkout (page hébergée)
- Billing (abonnements)
- Connect (marketplace)
- Radar (anti-fraude ML)
- Atlas (création de société US)

## Qu'est-ce que PayPal ?

PayPal est le pionnier du paiement en ligne (1998, ex-Confinity). C'est la marque la plus reconnue par les consommateurs.

**Chiffres clés 2026 :**
- **74.3% des entreprises IT** l'utilisent
- **400+ millions** de comptes actifs
- **Présence mondiale** : 200+ pays
- Confiance consommateur : **très élevée**

**Frais PayPal (2026) :**
- Transaction standard : **2.9% + 0.35€**
- Transaction internationale : **4.4% + frais fixes**
- PayPal Checkout : frais variables selon volume
- Micropaiements : offre spécifique

**Forces PayPal :**
- Confiance consommateur (marque connue)
- PayPal Credit / Pay in 4 (BNPL)
- Protection acheteur forte
- Pas besoin de saisir sa carte

**Faiblesses PayPal :**
- Frais élevés
- API vieillissante (vs Stripe)
- Support client difficile
- Blocages de compte fréquents

## Qu'est-ce qu'Adyen ?

Adyen est une plateforme de paiement enterprise néerlandaise (2006). Elle cible les grands comptes avec un modèle interchange++.

**Chiffres clés 2026 :**
- **250+ méthodes de paiement**
- Clients : **Uber, Spotify, eBay, McDonald's**
- Modèle : interchange++ (transparence totale)
- Cotée en bourse (Amsterdam)

**Frais Adyen :**
- **Interchange++** : frais interchange réels + 0.10-0.20€ + markup
- Pas de frais mensuels fixes
- Pas de frais de setup
- Volume minimum souvent requis

**Forces Adyen :**
- Transparence pricing (interchange++)
- Support enterprise premium
- 250+ méthodes de paiement locales
- Omnicanal (online + POS physique)

**Faiblesses Adyen :**
- Complexité pour petits volumes
- Pas idéal pour les startups
- Intégration plus complexe que Stripe

## Qu'est-ce que Mollie ?

Mollie est un PSP européen (Pays-Bas, 2004). Il cible les PME européennes avec une approche simple et des frais compétitifs.

**Chiffres clés 2026 :**
- **200K+ marchands** en Europe
- Focus : **Benelux, Allemagne, France**
- Méthodes locales : iDEAL, Bancontact, Klarna...

**Frais Mollie (2026) :**
- Carte crédit : **1.8% + 0.25€**
- Carte débit : **1.8% + 0.25€**
- iDEAL : **0.29€** fixe
- SEPA Direct Debit : **0.25€**

**Forces Mollie :**
- Frais compétitifs en Europe
- Méthodes de paiement locales
- Dashboard simple
- API correcte

**Faiblesses Mollie :**
- Moins de features avancées
- Support moins réactif que Stripe
- Pas idéal hors Europe

- Prorata automatique

- Customer portal (gestion self-service)

- Metered billing (à l'usage)

**PayPal Subscriptions** :
- Fonctionnel mais basique
- Moins de flexibilité
- UX consommateur connue

**Adyen** :
- Tokenisation et récurrence
- Moins intégré que Stripe
- Nécessite plus de développement

**Mollie** :
- Abonnements supportés

**Pour un SaaS** : Stripe Billing est le choix évident.

### Marketplace et paiements multi-parties

Si vous construisez une marketplace (vendeurs + acheteurs), vous avez besoin de "split payments".

**Stripe Connect** :
- Standard, Express, ou Custom onboarding
- KYC automatisé
- Split automatique
- Frais : 0.5% ou 2€/paiement
- Le plus complet du marché

**PayPal Commerce Platform** :
- Existe mais moins flexible
- Onboarding vendeur plus lourd

**Adyen for Platforms** :
- Solution enterprise
- Très complet mais complexe

**Mollie Connect** :
- Existe, moins mature

**Notre expérience** : pour une marketplace, Stripe Connect est quasi-obligatoire en 2026. Les alternatives sont soit moins bonnes, soit plus chères.

- SaaS avec abonnements

## FAQ

### Stripe est-il plus cher que les alternatives ?

Dépend du contexte. vs PayPal : non, 50% moins cher. vs Adyen interchange++ : similaire pour les gros volumes, légèrement plus cher pour les petits. vs Mollie : légèrement plus cher en Europe. Le vrai coût inclut le temps de développement : Stripe fait économiser des heures.

### Peut-on utiliser Stripe + PayPal ensemble ?

Oui, et c'est recommandé pour le B2C. Stripe en principal, PayPal en option de checkout. Certains consommateurs préfèrent PayPal (pas besoin de saisir leur carte). Attention : ça complexifie la réconciliation comptable.

### Stripe bloque-t-il des comptes comme PayPal ?

Moins fréquemment, mais ça arrive. Stripe est strict sur les activités à haut risque (crypto, adult, gambling). Pour les business classiques, les blocages sont rares. Conseil : lisez les Restricted Businesses avant de vous lancer.

### Quelle solution pour une marketplace en France ?

Stripe Connect, sans hésiter. C'est le plus complet, le mieux documenté, et le plus utilisé. Mangopay est une alternative française solide si vous voulez du local. Adyen for Platforms pour l'enterprise.

### Les frais Stripe sont-ils négociables ?

Oui, à partir de ~500K€/an de volume. Contactez Stripe Sales. Les réductions sont de l'ordre de 0.1-0.3% selon le volume et le secteur. En dessous, ce n'est pas worth it de négocier.

## Conclusion

En 2026, **Stripe reste le choix par défaut** pour les startups, SaaS, et marketplaces. La DX est inégalée, les features sont complètes, et les frais sont compétitifs.

**PayPal** est un complément utile pour le B2C. **Adyen** et **Mollie** sont des alternatives solides pour l'enterprise ou le marché européen.

Ne sur-optimisez pas les frais au détriment de la DX. 0.3% de différence sur 100K€ = 300€. Une intégration buggy vous coûte plus cher.
